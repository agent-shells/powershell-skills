# V0.4 and V0.5 Implementation Plan

Date: 2026-07-02

## Goal

Advance the project from GitHub-only installation to a publishable npm distribution and add a constrained read-only PowerShell helper for cmdlets.

## V0.4 Scope

- Add npm package metadata for `@agent-shells/powershell-skills`.
- Add a Node CLI named `powershell-skills`.
- Support `install codex`, `install claude-code`, and `install all`.
- Support `doctor` with human and JSON output.
- Support explicit `update` UX through npm, with dry-run support for verification.
- Keep PowerShell scripts as the source of truth; npm only dispatches to existing installers and diagnostics.
- Add CLI smoke tests and include them in release verification.

## V0.5 Scope

- Add a separate read-only PowerShell helper for allowlisted cmdlets.
- Keep `Invoke-AgentCommand.ps1` Application-only.
- Use structured JSON specs rather than free-form command strings.
- Reject aliases, functions, unknown cmdlets, unknown parameters, mutation cmdlets, scriptblocks, and destructive risk.
- Cover Windows PowerShell 5.1 and PowerShell 7 in smoke tests and CI.
- Update Codex and Claude Code adapters to route read-only cmdlet work through the new helper when structured output is useful.

## Non-Goals

- No automatic telemetry or failure upload.
- No automatic destructive command execution.
- No general unrestricted PowerShell command runner.
- No rewrite of the PowerShell core into Node.

## Verification

- `npm test`
- `npm pack --dry-run`
- `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-v0.1.ps1`
- `pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-v0.1.ps1 -PowerShellExe pwsh`
- GitHub Actions on `windows-latest` for `powershell.exe` and `pwsh`.
