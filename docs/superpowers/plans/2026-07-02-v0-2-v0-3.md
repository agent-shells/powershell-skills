# V0.2 and V0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.2 with real Windows PowerShell 5.1 and PowerShell 7 CI coverage, then ship v0.3 with Claude Code compatibility.

**Architecture:** Keep `core/` as the shared source of truth. Add version-specific adapters and installers without duplicating the pattern catalog. Release gates must prove CI files, compatibility wrappers, and adapter installers exist before tags are cut.

**Tech Stack:** PowerShell 5.1, PowerShell 7, GitHub Actions on `windows-latest`, Codex skills, Claude Code skills.
