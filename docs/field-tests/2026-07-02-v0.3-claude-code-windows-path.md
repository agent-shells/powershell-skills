# Field Test: Claude Code Windows Path Handling

Date: 2026-07-02

## Environment

- Agent: Claude Code
- Version: 2.1.158
- Mode: normal `claude -p`, non-bare
- Skill path: `%USERPROFILE%\.claude\skills\powershell-command-runner`
- OS context: Windows

## Scenario

Ask Claude Code to verify a file path containing both a space and Chinese characters:

```text
C:\Users\12279\AppData\Local\Temp\claude-skill-test-...\space path\中文.txt
```

## Expected Behavior

- Load or apply `powershell-command-runner` without requiring the user to type a slash command.
- Use a read-only command.
- Use PowerShell `Test-Path -LiteralPath` or an equally safe exact-path command shape.
- Return whether the file exists.

## Observed Behavior

- Claude Code exposed `powershell-command-runner` in slash commands.
- Explicit `/powershell-command-runner` invocation succeeded in normal mode.
- Without a slash command, Claude Code invoked the `Skill` tool with `powershell-command-runner`.
- Claude Code ran:

```powershell
Test-Path -LiteralPath 'C:\Users\12279\AppData\Local\Temp\claude-skill-test-...\space path\中文.txt'
```

- The command returned `True`.

## Result

Pass.

## Follow-Up

`--bare` mode returned `Unknown command: /powershell-command-runner` during explicit slash-command testing. Treat normal Claude Code mode as the supported skill path for v0.3.
